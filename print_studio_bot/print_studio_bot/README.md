# Telegram-бот студії індивідуальної друкованої продукції
Telegram-бот для супроводу клієнта під час замовлення друкованої продукції.
Бот допомагає клієнту:
- ознайомитися з умовами співпраці;
- зареєструватися;
- обрати тип продукції;
- вказати параметри замовлення;
- надіслати фотографії, документи та текстові матеріали;
- перевірити комплектність матеріалів;
- підтвердити замовлення;
- передати інформацію адміністратору або дизайнеру.
Поточна версія використовує кнопки, FSM-стани та правила перевірки. Зовнішня AI-модель або NLP у цій версії не підключені.
## Підтримувані продукти
- журнал;
- календар.
## Основна функціональність
### Реєстрація клієнта
Бот збирає:
- ім’я клієнта;
- номер телефону;
- Telegram ID;
- згоду з умовами співпраці.
### Замовлення журналу
Клієнт може:
- обрати підкатегорію журналу;
- обрати кількість сторінок;
- вибрати одну або декілька статей;
- надіслати фото передньої обкладинки;
- надіслати фото задньої обкладинки;
- надіслати фотографії для сторінок;
- додати матеріали для вибраних статей;
- пропустити матеріал, якщо він ще не готовий.
### Замовлення календаря
Клієнт може:
- обрати тип календаря;
- обрати варіант дизайну;
- обрати період;
- надіслати одну або декілька фотографій.
### Перевірка матеріалів
Бот перевіряє:
- наявність основних фотографій;
- наявність фотографій обкладинок;
- наявність фотографій для контенту;
- наявність матеріалів для вибраних статей.
Результат перевірки поділяється на:
- критично відсутні матеріали;
- рекомендовані до додавання матеріали.
### Робота із замовленням
Клієнт може:
- повернутися до попереднього кроку;
- додати додаткові матеріали;
- поставити питання адміністратору;
- змінити дані замовлення;
- скасувати замовлення через кнопку або команду `/cancel`;
- підтвердити замовлення.
Після підтвердження адміністратор отримує структурований звіт із даними клієнта, параметрами замовлення та завантаженими файлами.

## Технології
Python 3.11+
aiogram 3.x
Peewee
SQLite
python-dotenv
Встановлення
Клонувати репозиторій:
git clone <посилання-на-репозиторій>
cd print_studio_bot

## Встановити залежності:
python -m pip install -r requirements.txt

Створити Telegram-бота через @BotFather.

Створити файл .env у корені проєкту:

BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id

Запустити бота:
python bot.py

Команди
/start — почати роботу з ботом;
/cancel — скасувати поточне замовлення.
Поточні обмеження
FSM-стан зберігається в пам’яті та не відновлюється після перезапуску бота.
Сценарій календаря є спрощеним і не прив’язує фотографії до окремих місяців.
NLP та зовнішня AI-модель не використовуються.
Перевірка комплектності має rule-based характер.
