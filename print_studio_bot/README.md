# AI-менеджер студії індивідуальної друкованої продукції

Telegram-бот для супроводу клієнта під час замовлення друкованої продукції (журнали, календарі).

## Запуск

1. Встановити залежності:
   ```
   pip install -r requirements.txt
   ```

2. Створити бота через [@BotFather](https://t.me/BotFather) та отримати токен.

3. Створити файл `.env` за зразком `.env.example`:
   ```
   BOT_TOKEN=ваш_токен_тут
   ADMIN_ID=ваш_telegram_id
   ```
   (щоб дізнатись свій ID, напишіть [@userinfobot](https://t.me/userinfobot))

4. Запустити бота:
   ```
   python bot.py
   ```

## Реалізовано

**Коміт 1** — структура проєкту, модель БД (`Client`, `Order`, `OrderFile`), умови співпраці, реєстрація клієнта (ім'я, телефон), головне меню вибору продукту.

**Коміт 2** — FSM для журналу: вибір підкатегорії, кількості сторінок, вибір статей (мультивибір без пагінації).

**Коміт 3** — прийом фото та матеріалів із сортуванням за призначенням (обкладинка/зворот/контент/стаття), перевірка повноти комплекту з переліком критичних та попереджувальних відсутностей.

**Коміт 4** — спрощений сценарій календаря (тип/дизайн/період/фото), підтвердження замовлення та формування звіту адміністратору з усіма даними й файлами.

## Стек технологій

- Python 3.11+
- aiogram 3.x
- Peewee (SQLite)
- python-dotenv
