# AI-менеджер студії індивідуальної друкованої продукції

Telegram-бот для супроводу клієнта під час замовлення друкованої продукції (журнали, календарі).

## Запуск

1. Встановити залежності:
   ```
   pip install -r requirements.txt
   ```

2. Створити бота через [@BotFather](https://t.me/BotFather) та отримати токен.

3. Створити файл `.env` за зразком `.env.example`:
   ```
   BOT_TOKEN=ваш_токен_тут
   ```

4. Запустити бота:
   ```
   python bot.py
   ```

## Реалізовано (Коміт 1)

- Структура проєкту
- Модель бази даних: `Client`, `Order`, `OrderFile` (SQLite + Peewee)
- Показ умов співпраці та підтвердження згоди
- Реєстрація клієнта (ім'я, номер телефону)
- Головне меню вибору продукту (Журнал / Календар)

## Стек технологій

- Python 3.11+
- aiogram 3.x
- Peewee (SQLite)
- python-dotenv
